## Тема проєкту

**Кулінарний блог** — веб-проєкт для створення та ведення блогів на кулінарну тематику.

Основні можливості проєкту:
- реєстрація користувачів та вхід за логіном і паролем;
- перегляд та пошук рецептів;
- фільтрація рецептів за різними характеристиками;
- перегляд популярних рецептів;
- створення та редагування власних блогів і постів;
- коментування рецептів;
- оцінювання рецептів;
- адміністративне керування користувачами, блогами та постами;
- додавання, редагування та видалення контенту;
- блокування користувачів, блогів та постів.

## Первинне вивчення можливостей і вимог

Проаналізовано вимоги до командного курсового проєкту та визначено основні функціональні можливості майбутнього веб-застосунку.

Проєкт має бути реалізований на базі **ASP.NET Core** з використанням сучасних технологій .NET, системи контролю версій Git та методології Scrum.

## Технології

Попередньо планується використання:

- ASP.NET Core;
- Entity Framework Core;
- SQL Server;
- ASP.NET Core Identity для автентифікації та авторизації;
- HTML / CSS / JavaScript;
- Git / GitHub;
- REST API.

Також під час розробки планується використання принципів SOLID, патернів проєктування, LINQ, асинхронного програмування та інших технологій .NET.

## Software Requirements Specification (SRS)

Підготовлено SRS документацію для проєкту **«Кулінарний блог»**.

У SRS визначено:
- мету та призначення проєкту;
- функціональні вимоги;
- ролі користувачів;
- основні компоненти системи;
- вимоги до адміністративної та користувацької частин;
- основні технології реалізації;
- орієнтовні терміни виконання.
