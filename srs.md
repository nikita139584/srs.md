# 1. Вступ

## 1.1. Мета документа

Документ визначає основні функціональні та нефункціональні вимоги до веб-застосунку **«Кулінарний блог»** та використовується як основа для розробки, тестування і подальшого вдосконалення системи.

## 1.2. Обсяг продукту

| Напрямок | Опис |
|---|---|
| Реєстрація та авторизація | Створення облікового запису та вхід до системи |
| Рецепти | Перегляд, пошук і фільтрація рецептів |
| Блоги | Створення та редагування власних блогів |
| Пости | Створення, редагування та видалення постів |
| Коментарі | Додавання коментарів до рецептів |
| Оцінювання | Оцінка рецептів користувачами |
| Популярні рецепти | Формування списку популярного контенту |
| Адміністрування | Керування користувачами та модерація контенту |

## 1.3. Аудиторія документа

| Роль | Призначення |
|---|---|
| Team Lead | Планування та контроль реалізації |
| Developer | Розробка функціоналу |
| QA | Тестування вимог |
| Викладач | Перевірка відповідності завданню |
| Адміністратор | Перевірка адміністративних функцій |

## 1.4. Терміни та скорочення

| Термін | Визначення |
|---|---|
| MVC | Model-View-Controller |
| CRUD | Create, Read, Update, Delete |
| EF Core | Entity Framework Core |

# 4. Функціональні вимоги

## 4.1. Авторизація та реєстрація

| ID | Пріоритет | Вимога | Критерій прийняття |
|---|---|---|---|
| FR-01 | Must | Реєстрація нового користувача | Користувач може створити обліковий запис |
| FR-02 | Must | Авторизація користувача | При правильних даних виконується вхід |
| FR-03 | Must | Валідація полів | Некоректні дані не приймаються, показується помилка |

## 4.2. Рецепти

| ID | Пріоритет | Вимога | Критерій прийняття |
|---|---|---|---|
| FR-04 | Must | Перегляд списку рецептів | Користувач бачить доступні рецепти |
| FR-05 | Must | Перегляд одного рецепту | Відкривається сторінка з детальною інформацією |
| FR-06 | Must | Пошук рецептів | Пошук повертає відповідні результати |
| FR-07 | Should | Фільтрація | Можна фільтрувати рецепти за характеристиками |
| FR-08 | Should | Популярні рецепти | Відображаються рецепти з високим рейтингом |

## 4.3. Блоги та пости

| ID | Пріоритет | Вимога | Критерій прийняття |
|---|---|---|---|
| FR-09 | Must | Створення блогу | Авторизований користувач може створити блог |
| FR-10 | Must | Створення посту | Новий пост зберігається в БД |
| FR-11 | Should | Редагування посту | Автор може змінювати власний пост |
| FR-12 | Should | Видалення посту | Автор може видалити власний пост |

## 4.4. Коментарі та оцінювання

| ID | Пріоритет | Вимога | Критерій прийняття |
|---|---|---|---|
| FR-13 | Must | Додавання коментаря | Коментар зберігається та відображається |
| FR-14 | Must | Оцінювання рецепту | Оцінка користувача зберігається |
| FR-15 | Should | Розрахунок рейтингу | Рейтинг рецепту оновлюється після оцінки |

## 4.5. Адміністративна частина

| ID | Пріоритет | Вимога | Критерій прийняття |
|---|---|---|---|
| FR-16 | Must | Керування користувачами | Адміністратор може переглядати користувачів |
| FR-17 | Must | Блокування користувача | Заблокований користувач втрачає доступ до дозволених функцій |
| FR-18 | Must | Модерація постів | Адміністратор може редагувати або видаляти контент |
| FR-19 | Should | Модерація коментарів | Адміністратор може видаляти неприйнятні коментарі |

# 7. Припущення та залежності

| ID | Опис | Тип | Вплив |
|---|---|---|---|
| A-01 | SQL Server доступний під час роботи системи | Технічна залежність | Без БД система не може зберігати дані |

| A-04 | Браузер підтримує JavaScript | Клієнтська залежність | Частина валідації може не працювати |
